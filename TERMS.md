# TrendPulse terms of service

_Last updated: 20 November 2026_

TrendPulse (<https://trendpulse-sahil.streamlit.app>, source code
<https://github.com/SAHILinsights/trendpulse>) is a free, non-commercial, open-source portfolio
project by Sahil Sharma. It shows analytics about public YouTube trending videos.

## 1. Agreement to YouTube's terms

TrendPulse uses YouTube API Services. **By using TrendPulse you agree to be bound by the
[YouTube Terms of Service](https://www.youtube.com/t/terms).** YouTube data in TrendPulse is
handled as described in the [TrendPulse privacy policy](PRIVACY.md), which links to the
[Google Privacy Policy](https://policies.google.com/privacy).

## 2. What TrendPulse provides

- Read-only dashboards of public YouTube data and of TrendPulse's own analyses.
- Derived metrics (topic popularity score, growth, velocity, lifecycle stage, topic rankings) are
  calculated by TrendPulse, are labelled as such, and do not replace YouTube's own metrics.
- Each video links back to YouTube.
- Until live ingestion is approved, the dashboard runs on clearly labelled **SAMPLE** data from
  an offline simulator.

## 3. Acceptable use

- There are no accounts, and no personal data is collected from visitors.
- Do not attempt to scrape, overload or gain write access to the service or its database.
- No content is uploaded, modified or deleted on YouTube by TrendPulse.
